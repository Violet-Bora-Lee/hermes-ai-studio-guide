TROUBLESHOOTING

문제 해결

대부분은 채널 선택, 응답 위치, 대기열 세 가지를 확인하면 해결됩니다.

봇이 응답하지 않을 때

  1. 전용 채널 확인
    HQwen은 #local-qwen, Muse는 #local-muse, Media는 #video-gen에서 태그 없이 응답합니다.
  2. 공유 채널 확인
    #hermes-main과 아레나·공유 채널에서는 원하는 봇을 실제 @멘션합니다.
  3. 반응과 진행 표시 확인
    요청을 수신하면 이모지나 Working 상태가 표시될 수 있습니다.
  4. 응답 위치 확인
    전용 채널은 인라인, 멘션 기반 공유 채널은 자동 스레드에서 답변할 수 있습니다.

답변이 채널 본문에 안 보일 때

Hermes 계열 봇은 긴 작업의 소음을 줄이기 위해 요청 메시지에서 자동 스레드를 만들 수 있습니다. 요청 아래의 “메시지” 링크나 스레드 표시를 눌러 확인하세요.

로컬 모델이 느릴 때

  • 처음 요청은 모델 로딩 때문에 더 오래 걸릴 수 있습니다.
  • Muse는 긴 문맥과 도구 사용이 포함되면 수 분이 걸릴 수 있습니다.
  • HQwen은 빠른 작업에 Q4, 기본 Q5, 품질 우선 Q6를 선택합니다.
  • 영상 생성이 실행 중이면 GPU 공유 정책 때문에 텍스트 로컬 작업이 대기할 수 있습니다.

영상 생성이 오래 걸릴 때

영상 생성은 일반 채팅보다 훨씬 무겁습니다. 진행 상태가 보인다면 같은 요청을 반복 전송하지 말고 완료를 기다리세요.
상태의미행동
dry-run 통과요청과 백엔드 경로가 정상실제 렌더 요청 가능
대기 중GPU 잠금 또는 앞선 작업 처리 중중복 요청 금지
생성 중Wan이 프레임을 생성 중#video-gen 인라인 진행 확인
결과 URLMP4 생성 완료#video-results에서 확인

운영 상태 확인

일반 사용자는 #ai-ops의 상태 알림을 먼저 확인합니다. 반복 오류를 조사할 때만 #ai-logs의 상세 로그를 봅니다. 토큰이나 비밀번호를 로그 또는 채팅에 붙여넣지 않습니다.

안전 원칙

  • 봇 토큰, API 키, 비밀번호는 어떤 Discord 채널에도 게시하지 않습니다.
  • Mac Studio는 48GB 통합 메모리를 공유하므로 MUSE와 영상 모델의 고부하 작업은 직렬로 처리합니다.
  • 장시간 실제 렌더 전에 dry-run으로 프롬프트와 백엔드를 확인합니다.
  • 문제가 지속되면 채널 이름과 발생 시각만 운영 채널에 남깁니다.
