# Mac Studio AI Studio Guide

Discord에서 운영하는 Hermes, HQwen, Muse, Media 봇과 채널 구성의 공개 한국어 사용 설명서입니다.

## Pages

- `index.html` — 시작 대시보드
- `channels.html` — 채널 지도와 선택 기준
- `bots.html` — 봇별 역할과 전용 채널 대화 예시
- `workflows.html` — 글쓰기·로컬 추론·영상 생성 흐름
- `troubleshooting.html` — 문제 해결과 안전 원칙

공개 문서에는 Discord 서버 ID, 사용자 ID, Bot Token, API Key를 포함하지 않습니다.
