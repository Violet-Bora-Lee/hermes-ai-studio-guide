Hermes · 총괄 에이전트

강력한 GPT 모델과 전체 도구를 사용하는 기본 봇입니다. 조사, 코딩, 문서, 웹 작업, 자동화처럼 여러 단계가 필요한 일을 맡깁니다.

@Hermes 이 저장소를 분석하고, 문제를 재현한 다음 수정과 테스트까지 진행해줘.

HQwen · 로컬 범용 추론

Mac Studio에서 Qwen3.8-27B를 직접 실행합니다. 메모리와 속도에 따라 Q4·Q5·Q6 경로를 선택하며, 로컬 처리와 반복 작업에 적합합니다.

경로권장 상황특징
Q4빠른 초안과 반복가장 가볍고 빠름
Q5일반적인 기본 작업속도와 품질의 균형
Q6품질 우선 검토더 많은 메모리 사용

Muse · 한국어 글쓰기·편집

muse-glimmer-64k 로컬 모델을 사용합니다. 긴 문서의 맥락을 유지하면서 자연스러운 한국어, 톤 조정, 교정, 구조 개선을 담당합니다.

  • 공지문과 이메일 초안
  • 어색한 번역투 제거
  • 문체 통일과 분량 조절
  • 긴 글의 개요·제목·문단 재구성
@Muse 아래 글을 전문적이지만 딱딱하지 않은 한국어로 다듬고, 바뀐 이유를 세 줄로 설명해줘.

Media · 영상 오케스트레이터

요청을 해석하는 GPT 오케스트레이터와 실제 프레임을 만드는 Wan 2.2 TI2V-5B를 연결합니다. 요청 검증, dry-run, GPU 잠금, 결과 회수를 한 흐름으로 처리합니다.

중요: 실제 영상 생성은 수 분 이상 걸릴 수 있으며 통합 메모리를 많이 사용합니다. Media는 텍스트 로컬 모델과 영상 모델이 동시에 GPU 메모리를 다투지 않도록 작업을 직렬화합니다.
@Media 비 오는 서울 골목을 천천히 이동하는 시네마틱 영상. 16:9, 3초, 차분한 청색 톤으로 만들어줘.

멘션 규칙

  1. 전용 채널로 이동합니다.
  2. 입력창에서 @봇이름을 입력하고 자동완성에서 봇 계정을 선택합니다.
  3. 요청 조건과 원하는 결과 형식을 함께 적습니다.
  4. 요청 아래 생성된 스레드에서 진행 상황과 최종 답변을 확인합니다.
